Описание датасета repair_shops:
Placeid – ID города
• Houseunits – число домашних хозяйств в городе, шт
• Population – население в городе, человек
• Autoroute – индикатор транспортной доступности рынка {1, если город расположен на крупной автотрассе или имеет к ней доступ, и 0 иначе}
• Est811111 – мастерские по общему ремонту автомобилей, шт.
• Est811112 – мастерские по ремонту автомобильных трансмиссий, шт.
• Est811113 – мастерские по ремонту выхлопных систем, шт.
